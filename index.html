Tentang Saya

Saya adalah seorang pengajar dan pengembang di bidang Rekayasa Perangkat Lunak (RPL) SMKs IT Al-Mamun. Dengan minat yang kuat pada pengembangan backend, pengelolaan sistem basis data, serta perancangan media pembelajaran modern, saya memfokuskan diri untuk menciptakan solusi berbasis web yang efisien.

Selain membagikan ilmu teknis web development (PHP, SQL, & Web Tools), saya juga aktif mendampingi siswa dalam persiapan Praktik Kerja Lapangan (PKL), pembuatan portofolio digital, hingga pembentukan karakter profesional untuk dunia kerja IT.
